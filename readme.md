# 🤖 챗GPT를 활용한 파이썬 프로그래밍 실무

> **ChatGPT와 Python을 결합하여 기초 문법부터 업무 자동화, 데이터 분석, 미니 프로젝트까지 실무 중심의 개발 역량을 기르는 과정입니다.**

---

## 📌 교육 개요

- **과정명**: 챗GPT를 활용한 파이썬 프로그래밍 실무
- **총 교육 시간**: 39시간 (1일 3시간 × 총 13일)
- **교육 대상**: 
  - 파이썬을 처음 접하거나 기초를 다시 다지고 싶은 입문자
  - ChatGPT 등 생성형 AI를 활용해 코딩 생산성을 높이고 싶은 실무자
  - 반복 업무 자동화 및 데이터 처리가 필요한 직장인/학생
- **준비 사항**: PC/노트북, Python 3.x 환경 (또는 Google Colab / VS Code), OpenAI 계정

---

## 🎯 학습 목표

1. **AI 기반 코딩 학습법 습득**: ChatGPT 프롬프트 엔지니어링을 활용한 코드 생성, 디버깅, 최적화 기법을 체득합니다.
2. **파이썬 핵심 문법 마스터**: 변수, 제어문, 함수, 모듈 등 파이썬 필수 문법을 실습 중심으로 학습합니다.
3. **업무 자동화 구현**: 엑셀/CSV 데이터 처리, 파일 정리, 웹 크롤링 등 실무에 즉시 적용 가능한 자동화 스크립트를 작성합니다.
4. **실전 미니 프로젝트 완성**: 생성형 AI의 도움을 받아 아이디어 구상부터 완성된 파이썬 애플리케이션까지 직접 구축합니다.
